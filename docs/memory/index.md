# Memória de desenvolvimento

- [Após mudanças, reconstruir e reiniciar a aplicação em produção](rebuild-restart-apos-mudanca.md) — a URL do Tailscale Funnel serve o Next.js em modo produção; use `npm run app:up` / `app:down`, que encapsulam `.next` limpo, `setsid`, o servidor do standalone e a cópia dos estáticos. `[deploy, nextjs, tailscale, producao]`
- [npm ci exige lock gerado pela mesma versão de npm do runner](ci-lockfile-npm-runner.md) — regenerar `package-lock.json` com um npm diferente do usado no CI não corrige `EUSAGE`; é preciso casar a versão e fixar o patch do Node. `[ci, dependencias, npm]`
- [Mudança de UI atualiza o E2E no mesmo conjunto](mudanca-ui-atualiza-e2e.md) — alterações de interação ou contrato acessível exigem atualizar e executar o cenário E2E equivalente antes do push. `[ui, e2e, acessibilidade, playwright]`
- [E2E local exige AUTH_URL apontando para o host de teste](e2e-auth-url-local.md) — com o `AUTH_URL` do Tailscale, o Auth.js exige cookie `__Secure-` e todo cenário E2E autenticado é redirecionado à raiz; suba o servidor com o host e a porta do teste. `[e2e, autenticacao, playwright, nextauth, ambiente]`
- [Persistir não é o mesmo que voltar e ver](persistencia-visivel-apos-retorno.md) — "não persistiu" tem três causas (escrita, invalidação, derivação); feche o ciclo do teste voltando por navegação real ao ponto de partida. `[nextjs, app-router, cache, server-actions, e2e, persistencia]`
- [Estado que vive fora do React deve ser assinado, não espelhado](estado-offline-fora-do-react.md) — IndexedDB e `navigator.onLine` espelhados em `useState`+`useEffect` quebram o lint de hooks e criam janelas em que a UI afirma o oposto do estado real; use `useSyncExternalStore`. `[react, offline, indexeddb, hooks, eslint, outbox]`
- [Aritmética de dias locais ancora no meio-dia, não na meia-noite](aritmetica-de-dias-locais.md) — somar ±26h à meia-noite local para absorver horário de verão pula um dia inteiro; navegue a partir do meio-dia e cubra a ida e volta com teste. `[fuso-horario, datas, diario, e2e, validacao]`
- [Rigor de coleta é decisão de produto, não detalhe de formulário](protocolo-de-coleta-custa-friccao.md) — quando um protocolo da spec multiplica campos na tela, o custo de fricção precisa ser pesado explicitamente; a mudança percorre domínio, specs, ADR e UI no mesmo conjunto. `[produto, spec, adr, medicoes, formularios, dominio]`
- [Upload por Server Action estoura mudo no limite de 1 MB](upload-em-server-action-estoura-mudo.md) — o corpo acima de `bodySizeLimit` é rejeitado com 413 antes de a action rodar; nenhum erro chega à tela, o botão parece inerte e a suspeita cai na UI errada. `[nextjs, server-actions, upload, fotos, diagnostico, producao]`
- [Após o merge, sincronizar main e remover a branch concluída](limpeza-pos-merge.md) — encerrar cada PR com a `main` local atualizada e as branches de trabalho local e remota removidas. `[git, github, workflow, branches]`
- [Token de tipografia customizado precisa ser ensinado ao tailwind-merge](tokens-de-tipografia-e-tailwind-merge.md) — classe de escala inexistente cai em 16px sem erro, e o `tailwind-merge` trata `text-label-lg` como cor e descarta a cor real do componente. `[design-system, tailwind, tipografia, cn, ui]`
- [Job de cron em container roda com PATH mínimo e falha só na janela agendada](cron-em-container-perde-o-path.md) — o cron não herda ambiente nem PATH do PID 1, e a imagem `postgres:16` não traz agendador; valide com a agenda disparando de verdade, não com execução manual. `[docker, cron, backup, producao, diagnostico]`
- [O script `dev` não pode subir infraestrutura: ele é o webServer do E2E](dev-nao-sobe-infraestrutura.md) — acoplar `docker compose up` ao `npm run dev` quebra o job E2E, que já recebe Postgres como service; crie `dev:banco` em vez de alterar `dev`. `[ci, e2e, playwright, docker, scripts, ambiente]`
- [Sob um proxy de plataforma, publicar porta no host é conflito, não conveniência](porta-publicada-colide-com-o-proxy.md) — no Dokploy o Traefik entra pela rede interna e o `ports` do compose disputa a 3000 com o painel; deixe a publicação num overlay para a VPS sem plataforma. `[deploy, docker, compose, dokploy, traefik, producao]`
- [Em rede compartilhada, `db` não é um nome: é um alias disputado](alias-de-servico-colide-em-rede-compartilhada.md) — dois projetos com o serviço `db` na `dokploy-network` fazem o DNS responder em round-robin e o vizinho autentica no Postgres errado; `28P01` intermitente prova banco errado, não porta ocupada. `[deploy, docker, compose, dokploy, dns, postgres, diagnostico, producao]`
