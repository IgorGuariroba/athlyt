# Rótulos de triagem

| Papel canônico | Rótulo no GitHub | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Requer avaliação do mantenedor |
| `needs-info` | `needs-info` | Aguarda informações do autor |
| `ready-for-agent` | `ready-for-agent` | Especificado e pronto para agente autônomo |
| `ready-for-human` | `ready-for-human` | Requer implementação ou decisão humana |
| `wontfix` | `wontfix` | Não será executado |

Quando uma skill mencionar um papel de triagem, use o rótulo correspondente desta tabela.
